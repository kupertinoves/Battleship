# Практическая работа № 5
## Исследование потребительского рынка игровых приложений

**Жанр:** казуальная настольная игра / классическая стратегия (Battleship). **Регион:** Россия/СНГ.


## 1. Определение целевого сегмента

| Параметр | Значение | Тренд |
|---|---|---|
| Жанр | Казуальные настольные / board games | стабильный |
| Целевая аудитория | 25–45 лет, 55% мужчины | стабильная |
| Модель дохода | F2P + реклама / косметика | рост рекламной монетизации |
| Платформы | Android > iOS > ПК | переход к кроссплатформе |
| Конкуренция | Высокая, много клонов | насыщение |

**Анализ сегмента:** спрос на «вечные» игры стабилен: правила известны всем. Google Trends: запрос «морской бой» устойчив, с пиками осенью/зимой и в праздники (проверить по сервису).

## 2. Анализ конкурентов

| Конкурент | Платформа | Монетизация | Сильные стороны | Слабые стороны |
|---|---|---|---|---|
| «Морской бой» (казуальные студии) | Android/iOS | Реклама | Большая аудитория | Навязчивая реклама |
| Battleship Online (браузер) | Web | Реклама | Без установки | Устаревший UI |
| Battleship-клоны на Steam | ПК | Платно/F2P | Рейтинги | Мало игроков |
| Battleship Mobile (классика) | Mobile | IAP | Бренд | Нет обучения |

**SWOT нашего продукта:** *S* — обучение, рейтинг, бот, RU/EN; *W* — нет бренда, малый онлайн; *O* — свободная ниша «без рекламы»; *T* — крупные клоны.

**Вывод:** нужно конкурировать не геймплеем, а качеством: без рекламы, обучение, честный рейтинг.

## 3. Поведение пользователей

Источники: отзывы Google Play/RuStore, Reddit/VK-обсуждения. Типовые жалобы: реклама, нет соперников онлайн, слабый бот. Желаемое: быстрые матчи, рейтинг, друзья.

**Портрет игрока:** «Алексей, 27 лет, программист, играет в метро по 10 минут. Мотивация: расслабиться. Боль: реклама и ожидание соперника. Потребность: быстрый матч».

## 4. Тренды

Рост казуальных PvP-игр, кроссплатформенность, динамика обновлений, акцент на доступность (крупные шрифты, цвета), социальные функции. Для проекта: добавить режим «с другом по коду комнаты», ежедневные задания.

## 5. Отчёт и рекомендации

1. Запустить на ПК (itch.io) → затем Android (RuStore).
2. Монетизация: без рекламы, косметические скины и фоны (в игре уже есть «Поменять фон»).
3. Приоритет: онлайн-матчмейкинг с ботом-заместителем при ожидании соперника >15 с — решает проблему «пустого онлайна».
4. Первый KPI: 1 000 установок и retention D1 ≥ 30%.

## 6. Критерии оценки исследования
Полнота анализа рынка, количество конкурентов (≥ 3, выполнено — 4), качество выводов, практичность рекомендаций, оформление.
